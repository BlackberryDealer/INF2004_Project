# Abbreviations — CSC28 PicoCar

BARR-C 7.1 asks for meaningful names; these are the only abbreviations allowed
in identifiers without spelling them out. Add a row by pull request before
using a new one.

| Abbreviation | Meaning |
|---|---|
| ADC | Analogue-to-digital converter |
| BAR | Barcode |
| C39 | Code 39 (barcode symbology) |
| CAL | Calibration |
| CMD | Command |
| CNT | Count |
| CPW | Encoder counts per 50 ms speed window (`_cpw` suffix) |
| DDEG | Tenths of a degree, 0.1° (`_ddeg` suffix) |
| CDEG | Hundredths of a degree, 0.01° (`_cdeg` suffix) |
| DPS | Degrees per second (`_dps` suffix) |
| ENC | Encoder |
| EVT | Event |
| FLG | Event flag (kernel object) |
| HB | Heartbeat |
| IMU | Inertial measurement unit (LSM303DLHC) |
| IRQ | Interrupt request |
| ISR | Interrupt service routine (`_isr` suffix) |
| JCT | Junction |
| LAT | Latency |
| MBF | Message buffer (kernel object) |
| MCLASS | Motion class |
| MQ | MQTT |
| MTX | Mutex (kernel object) |
| NFR | Non-functional requirement |
| ODO | Odometry |
| PID | Proportional-integral-derivative controller |
| PIO | RP2040 programmable I/O block |
| POS | Position |
| PRV | Private (layout rows owned by one module) |
| PWM | Pulse-width modulation |
| RNG | Range-assumption encoding kind (`APP_KIND_RNG`) |
| SAT | Saturating encoding kind (`APP_KIND_SAT`) |
| SB | Status board |
| SEM | Semaphore (kernel object) |
| SM | State machine (PIO state machine or software) |
| US | Ultrasonic, or microseconds by context: the `_us` suffix always means microseconds |
| WCET | Worst-case execution time |
