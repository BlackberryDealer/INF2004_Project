Setup

Run Mosquitto with a WebSocket listener (add listener 9001 and protocol websockets to C:\mosq\car.conf), then run py tools\dashboard\car_link.py: it tells the car the laptop's address (UDP beacon, so a new hotspot needs no rebuild) and serves this page at http://localhost:8000. Connect to localhost (or the laptop's IP) and port 9001. No car? Run py tools\dashboard\fake_car.py for a pretend one. Full steps: tools/dashboard/README.md. Decoding matches tools/telem_decode.py byte for byte (host test S1-U44).
